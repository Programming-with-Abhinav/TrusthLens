# Application start guide

## 1) Start the app from the terminal

From the project root, run:

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 5500
```

## 2) Open the app in the browser

Visit:

```text
http://localhost:5500
```

API docs are available at:

```text
http://localhost:5500/docs
```

This project is ready for local development and launch checks.
